# Curriculum

Handlers and DTOs for curriculum authoring in the Learning module: tracks, modules, lessons, quizzes, assignments, badges and progression (ADR 0043, L1-023). Tracks, modules and lessons arrived with prompt 56, quizzes and assignments with prompt 60, and badges (`BadgesHandler`, `BadgeCommands`, `BadgeAwarder`, `BadgeAwardCommand`) and the progression framework (`ProgressionHandler`, `ProgressionCommands`) with prompt 64 (ADR 0058).
