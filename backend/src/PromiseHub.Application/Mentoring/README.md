# Mentoring

Handlers and DTOs for the Mentoring module: mentor assignments, mentor check-ins, at-risk flags and grading (ADR 0043, L1-024). Further handlers arrive with prompts 54 to 69; at-risk flags are `AtRiskFlagsHandler` (prompt 68, ADR 0062); assigning work is `AssignWorkHandler` (prompt 69, ADR 0063).
