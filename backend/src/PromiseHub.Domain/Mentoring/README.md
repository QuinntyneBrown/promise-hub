# Mentoring

Domain types for the Mentoring module: mentor assignments, check-ins, at-risk flags and grading (ADR 0043, L1-024).

- `YouthMentor` — the one mentor a child has in an organization (prompt 54, ADR 0048).
- `CohortMentor` — a mentor on a program's team, lead or supporting (prompt 54, ADR 0048).

Check-ins, at-risk flags and grading arrive with prompts 63 to 69.
