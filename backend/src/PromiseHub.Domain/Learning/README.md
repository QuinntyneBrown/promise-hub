# Learning

Domain types for the Learning module's youth side: lessons, quizzes, assignments, reflections, journey and badges (ADR 0043, L1-023). `YouthOnboarding` holds a youth's first-run setup (L2-059, ADR 0047); `LessonProgress`, `CodingWorkspace` and `ProjectSubmission` hold lesson progress (ADR 0051); `QuizAttempt` holds a youth's quiz attempts (ADR 0055); the other types arrive with the journeys of prompts 62 to 66.
