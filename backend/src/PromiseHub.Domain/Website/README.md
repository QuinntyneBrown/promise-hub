# Website

Domain types for the Public website module (ADR 0043, ADR 0075, L1-025): the requests a visitor sends from an organization's public pages, each owned by that organization.

- `ContactMessage` — a message from the contact page.
- `VolunteerInterest` — an offer to volunteer, with the screening acknowledgement.
- `DonationPledge` — a monthly donation started with the payment provider; the provider's reference only, never card details.
