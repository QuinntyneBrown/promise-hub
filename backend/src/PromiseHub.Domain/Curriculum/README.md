# Curriculum

Domain types for curriculum authoring in the Learning module (ADR 0043, ADR 0050, L1-023): `Track`, `CurriculumModule`, `Lesson` and `ContentStatus` (prompt 56); `Quiz`, `QuizQuestion`, `QuestionType`, `FeedbackMode`, `Assignment`, `RubricCriterion` and `SubmissionTypes` (prompt 60, ADR 0054). `Badge`, `BadgeKind`, `BadgeRule`, `BadgeAward` and `ProgressionStage` (prompt 64, ADR 0058).
