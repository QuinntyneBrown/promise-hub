# Support

## Questions and help

- Read the [README](README.md) and the documentation in [`docs/`](docs/).
- Search existing issues; your question may already be answered.
- Open a new issue if you can't find an answer.

## Bugs and feature requests

Use the [bug report](.github/ISSUE_TEMPLATE/bug_report.md) or [feature request](.github/ISSUE_TEMPLATE/feature_request.md) template.

## Security issues

Do not report vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md).

## Conduct concerns

See the [Code of Conduct](CODE_OF_CONDUCT.md).
