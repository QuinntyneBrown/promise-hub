# Screen composition

Each screen from `docs/mocks/` and the components-library components it is composed of. Anything not listed under a library component is feature composition only. Updated as screens are built.

## Shell

| Part | Mock | Library components | Built locally |
|---|---|---|---|
| Skip link | every page | `ph-skip-link` | — |
| Top bar | every staff page; participant variants `today/youth`, `today/mentor`, `today/volunteer`, `today/youth-learning-off`, `my-schedule` (Today, Check-in and Schedule for volunteers) | `ph-top-bar` (`ph-brand-mark`, `ph-avatar`, `ph-icon`); search hidden for participant roles | Navigation list filtered by module and role (`shell/navigation.ts`, ADR 0043) |
| Phone tab bar | every staff page and the participant variants | `ph-bottom-navigation` | — |
| Account menu | `account-menu` | `ph-top-bar` (CDK Menu) | Sign out calls `AUTH_API` |
| More menu | `main-menu` (default, director, admin with People, youth, mentor, volunteer; youth and mentor list Messages and Announcements while Messages is on) | `ph-nav-drawer` via `NavDrawerService` | Drawer data from the session and role |
