Secrets stay secret

  • Links stored as hashes; passwords as salted PBKDF2 hashes
  • The request log keeps /auth/reset-password/{token}, never the token
  • The audit entry names the account, never the token or the password
  • The token in the clear: only in the email

How it is tested

  • PasswordResetForEveryRoleTests: no enumeration, the limit, the newest link, deactivation, policy, sessions, audit, logs
  • PasswordResetTests and PasswordPolicyTests: the staff path still holds
  • reset-a-password.spec.ts: Sofía, Daniel and Lucía with axe, on a laptop and a phone

Things to remember

  • The answer never says whether an address has an account
  • Three links an hour; only the newest works, once, for an hour
  • One rule for everyone; other sessions end; the role home opens
