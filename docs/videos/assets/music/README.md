# Background music

Every PromiseHub video has this track under its narration. Every deck names it with
`<body data-music="../assets/music/on-the-beach-intro-outro.mp3">`; the video builder lays it
under the narration, looped if it is shorter, at `data-music-db` (default −10.8 dB), faded in,
and holds the last slide 3 s after the narration so the music plays on and fades out. The
builder refuses a deck with no `data-music`. Keep the provenance of every track here.
