Quiz approvals

Nadia’s 75% approved with an override of 80, then Approve all.

Only approved scores count

  • POST /mentoring/quiz-attempts/{id}/approve with an optional override, 0 to 100
  • AutoScore kept; the approved score becomes the attempt's score and pass
  • POST /mentoring/quiz-approvals/approve-all: each at its auto-score, each audited
  • Set per quiz: Mentor approves each score
