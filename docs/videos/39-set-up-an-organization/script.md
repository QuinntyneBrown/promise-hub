# 39 · Set up an organization

A new organization shouldn't need a consultant to get started. This video shows the setup checklist: what is done, what comes next, and how an admin can leave and come back without losing anything.

## What setup promises

Setup has up to six steps: name the organization, choose modules, create the first program, import the children, invite staff, and send a first permission slip. Each step is done when the organization's own data says so, so there is nothing separate to save. The first-slip step only appears when Permission slips is on. Each step links to the screen that already does that job. Leave with Finish later, come back to Set up, and the checklist is exactly where you left it.

## Grace names Northgate

Here is Set up on Grace's laptop. Northgate already has a program and children, so those are done, and naming the organization is next. Grace opens the step, changes the name to Northgate Kids, and saves. Back on the checklist, the step is ticked and staff is next.

## Mistakes and who can set up

If the name is left empty, the page says so and nothing is saved. Site leads who open setup are told that admins set up the organization.

## How it is tested

Backend tests cover which steps are done for a new organization, saving the organization step, an empty name refused with nothing saved, Harbourview's progress, and site leads refused while each organization keeps its own setup. The browser tests cover the checklist, the empty name, saving and coming back, and the forbidden page, with accessibility checks.

## Recap

Things to remember. Progress comes from the organization's data. Every step reuses the screen that does the job. Finish later loses nothing. Next, switching between organizations.
