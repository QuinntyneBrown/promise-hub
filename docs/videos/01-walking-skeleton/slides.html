The walking skeleton

Tenancy, migrate and seed, audit recording and the shell

What the skeleton promises

  • The CLI migrates and seeds two organizations, safely re-run
  • Every query filtered by the signed-in membership's organization
  • Sensitive actions written to an append-only audit log
  • A shell built only from the components library

Migrate and seed

dotnet run --project backend/src/PromiseHub.Cli -- migrate
dotnet run --project backend/src/PromiseHub.Cli -- seed
dotnet run --project backend/src/PromiseHub.Cli -- migrate --check   # exit 3 when pending

One tenant at a time

  • TenantContextMiddleware resolves the membership from the session
  • A query filter adds OrganizationId to every tenant-owned query
  • Saving a row for another organization throws

Things to remember

  • The CLI owns the schema and the seed
  • The membership decides the tenant, never the client
  • Audit entries are permanent
  • Every screen comes from the components library
