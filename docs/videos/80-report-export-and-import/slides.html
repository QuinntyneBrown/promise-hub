Rules on the server

  • Reports module and ViewReports: admins, program directors, site leads; others 403
  • Staff activity needs Mentoring, the progress board Learning: off answers 404
  • A Youth email column needs Learning and an admin (ManageStaff), else 422
  • Another organization’s cohort or child: 404, never counted
