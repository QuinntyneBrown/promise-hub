Things to remember

  • The agreement is accepted in Settings, before the module is on
  • A named signer gets one single-use link at a time
  • Coverage is counted on the server; Admin and Program director always see status
  • Fixed wording; only the sender name changes
  • A new version disables Launch until accepted
