Three roles that see only what is theirs

  • Youth: one account, one child record, Learn
  • Mentor: only assigned youth and cohorts, MentorYouth
  • Volunteer: only assigned sessions, RunSessions without RunAnySession
  • Staff endpoints need UseStaffApp; every new endpoint names its module and permission
