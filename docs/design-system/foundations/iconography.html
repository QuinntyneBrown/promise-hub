Iconography

Outline icons support written labels; colour alone never identifies a medical or attendance state.

Principles

Use the existing 24-unit view box, currentColor stroke and 16/20/24px semantic sizes. Decorative SVGs set aria-hidden. Icon-only actions require an explicit verb and object name and a focus-accessible tooltip. Do not use an icon as the only allergy or pickup instruction.
