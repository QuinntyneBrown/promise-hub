Principles

Light is the root default. Dark follows the operating-system preference unless data-theme forces light or dark. The explicit dark block and OS dark block use the same values. Native controls follow color-scheme. Forced-colours defers borders and focus to system colours; increased contrast strengthens muted text and dividers.

The DTCG tokens.json export is generated from tokens.css. Add a theme by overriding semantic roles, then run every contrast pair before publishing. Side-by-side examples explicitly scope both themes.
