Responsive

Below 640px, keep a single reading column, allow long names to wrap and retain 16px page margins. At 768px the grid becomes eight columns with 24px gutters and 32px margins. At 1024px use twelve columns with 32px gutters and 48px margins. At 1280px the main container caps at 80rem; 1536px adds no extra content width.

Controls wrap inside their available width. Hover is an enhancement; labels and recovery actions remain available to touch and keyboard users. No essential content is hidden at a breakpoint.

Theming

Read semantic roles rather than palette values. Light and dark specimens share markup. A nested theme scope recomputes foregrounds and surfaces; status colours retain their named meanings. Keep organization accent foreground and background as one validated pair.

Accessibility

Role and pattern

Follow the WAI-ARIA APG landmarks pattern where applicable. Use native HTML first; descriptive containers have no added widget role. Static dialog specimens are labelled groups rather than active modals.

Keyboard map

KeyResult
Tab / Shift+TabMove through controls in reading order.
EnterSubmit only from the expected form context; retain values on failure.

Focus and labels

DOM order matches reading order. Use the shared focus ring and offset; do not cover it with sticky actions. The visible name supplies the accessible name. Link help and errors through aria-describedby. Dialogs move focus to the heading or first useful control, trap it while open, then return it to the opener. Background content becomes inert. Routine status updates never steal focus.

Motion and touch

Transitions read duration and easing tokens. Reduced motion minimizes transitions and stops decorative loops. Targets are at least 24px; routine phone controls are 44px or larger. Allow 8px separation for compact actions. Hover-only instructions must also appear on focus; neither hover nor dragging is required to complete a task.

Content

Use sentence case, specific verbs and real object names: “Check in Mateo”, “Send permission slip”, “Save guardian”. Preserve accents in names such as Sofía. Say why an action failed and how to fix it; retain entered values. Never expose private medical details in a general message or notification preview. Status, dates and counts are written in text, not only colour or iconography.
