When

Use a page for long reading or several decisions. Use a modal for a short focused edit or confirmation, a drawer for navigation and a popover for short contextual content. Do not stack competing modals. Restore focus to the opener; use Angular CDK Dialog/Overlay in the application.

Structure

  1. Dialog — Ask for a focused decision or edit while preserving the calling context.
  2. Menu — Offer secondary account actions without obscuring the current task.
  3. Tooltip — Clarify an icon control on focus and hover without carrying essential instructions.

States

StateBehavior
DefaultShow current context and one primary next action.
Loading / submittingKeep layout stable, name the ongoing work and prevent duplicate submission.
SuccessDescribe what changed and retain the path back.
Empty / no resultsExplain the distinction and offer a relevant next action.
Error / invalidRetain context and values, describe correction or retry.
Offline / forbiddenState the limitation explicitly; do not imply an action was persisted or authorized.

Responsive

One column and 16px margins on phones; related fields and panels may share columns from 768px. Use 24px tablet and 32px desktop gutters. Actions wrap without losing reading order. A table scrolls in its own region and long translated text remains visible. Sheets use available device height and preserve safe-area padding.

Accessibility

Retain heading and landmark order, visible labels and focus. Announce routine updates politely and urgent new errors assertively. Move focus only for navigation, modal entry or a failed-submit error summary. Never require a pointer, hover, colour recognition or dragging. Support reduced motion, zoom and forced colours. See the accessibility contract.

Content

Use a page for long reading or several decisions. Use a modal for a short focused edit or confirmation, a drawer for navigation and a popover for short contextual content. Do not stack competing modals. Restore focus to the opener; use Angular CDK Dialog/Overlay in the application.

Use concrete family-facing language, sentence case and locale-aware dates. Do not put private information into a broadly visible preview.
