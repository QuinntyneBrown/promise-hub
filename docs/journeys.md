| Guardian | Update household details | Correct contact, medical, language, and child information through a verified link. |
| Guardian | Manage approved pickups | Add or remove adults authorized to collect a child. |

| Guardian | Complete a survey | Submit feedback or outcomes through a translated, verified page. |

| Site lead | Sign children out | Verify pickup authority and record who collected each child. |
| Site lead | Read a Quick Card | Find allergies, medication, emergency contacts, and pickup rules immediately. |
| Site lead | Run check-in offline | Use the cached roster and sync queued attendance when connectivity returns. |
| Site lead | Resolve missing slips | See who lacks consent and collect a signature on a tablet. |
| Site lead | Follow up no-shows | Review missing children and guardian responses after alerts. |
| Site lead | End a session | Reconcile attendance and close the day's session. |
| Site lead | Report an incident | Record what happened and submit it for supervisor review. |
| Program director | Create programs and events | Set schedules, capacity, and event details for enrolled children. |
| Program director | Send permission slips | Write event consent, contact guardians, and monitor signatures. |
| Program director | Review incidents | Examine submitted reports and record follow-up decisions. |
| Program director | Send guardian messages | Choose recipients, language, and channel; review delivery and failures. |
| Program director | Produce grant reports | Filter attendance, demographics, and outcomes and export funder-ready results. |
| Program director | Manage waitlists | Review capacity and move eligible children into programs. |
| Program director | Monitor today's work | See sessions, missing slips, alerts, and tasks in one place. |
| Admin / office manager | Set up an organization | Choose modules and create the first program, roster, staff, and slip. |

| Admin / office manager | Maintain households | Edit guardians, children, medical details, and approved pickups. |
| Admin / office manager | Configure modules | Enable or disable modules while respecting dependencies and preserving data. |

| Admin / office manager | Configure privacy | Set data residency, retention, and guardian data request handling. |
