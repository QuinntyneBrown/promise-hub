Your First Webpage

Web Basics · Lesson 1 of 2 · Coding · 20 min

1. Every page has a skeleton

HTML uses tags in angle brackets. A tag that opens must also close. Here’s the smallest real page:

<!doctype html>
<html>
  <head><title>My Page</title></head>
  <body>
    <h1>Hello!</h1>
  </body>
</html>

2. Add a heading and a paragraph

Put content inside <body>. Use <h1> for a title and <p> for a paragraph.

<body>
  <h1>Harbourview Youth Night</h1>
  <p>Come build, belong and grow.</p>
</body>
