# learning

Feature library for the Learning module: the youth's home, tracks, modules, reading and scripture lessons with their video, coding lessons and coding projects (prompt 57), quizzes with their intro, attempt, submit-quiz dialog and result (prompt 61), assignments with their brief, submit page, submit-assignment and unsaved-changes dialogs, the unsaved-changes guard and the submission's status (prompt 62), plus first-run setup; reflections, journey and badges arrive with later journeys (ADR 0043, ADR 0051, ADR 0055, ADR 0056). Maps to the Learning module and is lazy-loaded only while it is on. Depends only on `@promisehub/api` and `@promisehub/components`.
