# learning

Feature library for the Learning module: the youth's home, tracks, modules, reading and scripture lessons with their video, coding lessons and coding projects (prompt 57), plus first-run setup; quizzes, assignments, reflections, journey and badges arrive with later journeys (ADR 0043, ADR 0051). Maps to the Learning module and is lazy-loaded only while it is on. Depends only on `@promisehub/api` and `@promisehub/components`.
