# attendance

The Roll Call and Quick Cards feature library. Routes: `/check-in` (today's session roster with check-in, late, excused, absent, Mark the rest present, walk-ins, sign-out, session notes and ending, offline queue), `/check-in/history` (attendance history and rates with audited corrections) and `/quick-cards/:childId`. Depends only on `@promisehub/api` and `@promisehub/components`.
